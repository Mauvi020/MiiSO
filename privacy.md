## 1. Welche Daten werden verarbeitet und warum?
Unsere Discord-Anwendung (Bot) verarbeitet nur Daten, die für die Bereitstellung der Funktionen zwingend erforderlich sind. Dazu gehören:

* **Discord User-IDs & Server-IDs:** Diese eindeutigen Nummern werden verwendet, um Einstellungen (z. B. Konfigurationen, Server-Präfixe oder Spielstände) dem jeweiligen Nutzer oder Server zuzuordnen.
* **Temporäre Daten:** Eingegebene Befehle (Slash-Commands) verarbeiten kurzzeitig die von Ihnen eingegebenen Parameter, um die gewünschte Aktion auszuführen.

Wir speichern *keine* Klartext-Namen, Passwörter, E-Mail-Adressen oder vollständigen Nachrichtenverläufe (Chat-Logs), es sei denn, dies ist für eine explizite Funktion (z. B. ein Log-System) zwingend notwendig.

## 2. Rechtsgrundlage der Verarbeitung
Die Verarbeitung der Daten erfolgt auf Grundlage Ihrer Einwilligung bzw. zur Erfüllung der Funktionen, die Sie durch die Nutzung des Bots oder durch das Hinzufügen auf einen Server anfordern (Art. 6 Abs. 1 lit. b und f DSGVO).

---

## 3. Speicherdauer und Löschung
Die Daten werden nur so lange gespeichert, wie die Anwendung auf Ihrem Server aktiv ist oder wie es für die Bereitstellung der Funktionen nötig ist. 

* Wenn der Bot von einem Server entfernt („gekickt“) wird, werden die serverspezifischen Daten in der Regel automatisch oder bei der nächsten Bereinigung gelöscht.
* Nutzer können die Löschung ihrer gespeicherten Daten jederzeit anfordern (siehe Kontakt).

---

## 4. Weitergabe an Dritte
Es findet keine Weitergabe, kein Verkauf und keine sonstige Übermittlung Ihrer Daten an unbefugte Dritte statt. Die Daten verbleiben ausschließlich auf der Infrastruktur, die für den Betrieb des Bots genutzt wird.
